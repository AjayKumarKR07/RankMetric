# RankFlow

RankFlow is an AI-powered SEO analysis and website auditing platform built with React, TypeScript, Vite, and Tailwind CSS. It helps website owners, developers, and marketers analyze SEO performance, monitor rankings, identify technical issues, and improve search engine visibility.

## Features

* Website SEO Analysis
* Performance & Speed Audits
* Keyword Tracking
* Competitor Monitoring
* Accessibility Checks
* SEO Score Reports
* Actionable Recommendations
* Interactive Dashboard
* Historical Ranking Data

## Tech Stack

### Frontend

* React
* TypeScript
* Vite
* Tailwind CSS
* React Router
* Lucide React

### Backend

* Node.js
* Express.js

## Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/rankflow.git
```

Navigate to the project directory:

```bash
cd rankflow
```

Install dependencies:

```bash
npm install
```

## Run Development Server

Frontend:

```bash
npm run dev
```

Backend:

```bash
cd backend
npm install
npm start
```

## Build for Production

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```
